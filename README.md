# 🕐 Telegram-бот для учёта рабочего времени

Telegram-бот для учёта рабочего времени сотрудников с расчётом зарплаты от оклада и месячной нормы часов.

## 🚀 Возможности

### Для сотрудников:
- ▶️ Начать/завершить рабочую смену
- ☕ Управление перерывами (обед, кофе, перекур, технический, другой)
- 📊 Отчёт за сегодня
- 📈 Статистика за месяц
- 💰 Расчёт зарплаты

### Для администраторов:
- 👥 Управление сотрудниками
- 💰 Изменение окладов
- 📅 Изменение нормы часов
- 🔄 Автоматический/ручной расчёт нормы часов
- ✅ Отметка аванса и зарплаты как выплаченных

## 📐 Расчёт зарплаты

**Формула:**
- Часовая ставка = Оклад / Норма часов за месяц
- Зарплата = Отработанные часы × Часовая ставка
- Аванс = 40% от начисленной суммы
- Зарплата = 60% от начисленной суммы

**Пример:**
- Оклад: 200 000 ₽
- Норма часов: 168 ч
- Часовая ставка: 200 000 / 168 = 1 190.48 ₽/ч
- Отработано: 180 ч → Начислено: 214 285.71 ₽ (переработка: +12 ч)
